MERIDIAN — исправленная автономная версия

1. Распакуйте ZIP целиком.
2. Откройте MERIDIAN/index.html в Chrome, Edge, Safari или Firefox.
3. Кухня и Управление доступны внизу страницы.

PHP, SQL, npm и запуск сервера не нужны.
Не открывайте HTML в предпросмотре ZIP или приложении «Файлы»: такой просмотр может не выполнять JavaScript. Откройте распакованный index.html именно в браузере на компьютере.

Адреса разделов используют #, например index.html#/kitchen.
Если браузер разрешает локальное хранилище, изменения сохраняются. Без доступа к нему приложение работает в памяти до закрытия страницы.
Для надёжной синхронизации соседних вкладок можно запустить в этой папке:
python3 -m http.server 8080
и открыть http://localhost:8080

Это прототип без пароля администратора и без обмена заказами между разными устройствами.
